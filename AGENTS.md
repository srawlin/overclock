# fastcode-pi

Cerebras-tuned coding harness: a thin extension on `@mariozechner/pi-coding-agent` (pi), launched via `bin/fastcode`. See `README.md` for the why and usage.

## Required workflow — tests, commit, push

**After ANY code change, before telling the user it's done:**

1. `npm test` — runs `bun` on each `test/*.test.ts` (script-style tests using `process.exit`, NOT `bun test` discovery). Includes a local-mock e2e (`test/e2e.test.ts`) — no API key needed.
2. `bun typecheck` — `tsc --noEmit`, must be clean.
3. Commit on `dev` with a conventional message (`fix(fastcode):`, `feat(fastcode):`, `test:`, `docs:`, `chore:`).
4. `git push origin dev`.

`npm run eval` (`node test/eval/run.mjs`) is the deeper real-API task eval — uses the caller's Cerebras key and burns tokens; run when the change could affect agent behavior or speed, not for every commit.

## Repo facts

- Default/only branch: `dev`. Remote: `git@github.com:srawlin/fastcode.git`.
- Runtime: pi (node ≥20); tests run under bun. The launcher resolves both itself.
- Extension entry: `extensions/fastcode/index.ts`; tests live in `test/*.test.ts`.
- Do not hand-edit `test/eval/results/` (generated by the eval harness).
